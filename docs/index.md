## Project overview
- **Type:** monorepo with 4 parts · **Primary languages:** TypeScript (Next.js 16 + NestJS 10) · **Architecture:** Server-Components-first frontend + modular NestJS backend, five-layer defense-in-depth.
- **What it is:** AuraHire — an explainable, fair AI-powered recruitment platform (thesis). See [project-overview.md](./project-overview.md).
- **⚠️ Active migration:** off Digital Ocean → fully serverless (Vercel + **Neon** Postgres + **Upstash** Redis); auth re-platformed off Supabase; domain → `aurahire.cjjutba.com`. See [deployment-guide.md](./deployment-guide.md) and the **Migration State** table in [`_bmad-output/project-context.md`](../_bmad-output/project-context.md).

## Conventions reminder (for any agent)
Frontend never touches DB/AI/secrets · Zod schemas in `packages/shared` are the single source of truth · every AI call: PII-redact → structured output → audit · every mutation: audit + cache-invalidate · RLS never disabled · numbers render in JetBrains Mono · read `apps/web/node_modules/next/dist/docs/` before Next.js 16 code · don't hard-code retired infra (Supabase/DO/`aurahire.site`).
