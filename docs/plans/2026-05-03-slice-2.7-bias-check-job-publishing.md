# Slice 2.7 — Bias Check + Job Publishing Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (in the executing session) to implement this plan task-by-task. Dispatch a fresh subagent per task; review between tasks; halt on failure. **This slice closes the thesis loop on the _fairness_ angle** — every job description is run through bias detection before publish, every flag is auditable, and recruiter overrides require a written reason that stays on the record.

**Goal:** Ship the **upstream bias intervention** that defines AuraHire's "active mitigation, not just monitoring" thesis claim. Backend gets: real `DetectBiasService.check()` (replacing 2.3 shell); a new `BiasModule` with persistence + override flow; `JobsService.publish()` rewired to re-run scan, persist flags, and **block publish with HTTP 422** if any flag is unresolved. Frontend gets: a `BiasFlagChip` + popover component; debounced inline scanning in the job description editor (preview only, not persisted); a publish flow that on 422 opens an **Override Modal** showing each flagged term with edit-or-justify choices. By end of this slice: a recruiter who types "rockstar" sees an inline amber chip while typing, then on Publish gets blocked with a modal listing the flag and requiring either an edit or a written override — and every decision is in `audit_logs`.

**Architecture:** Three layers collaborate. (1) `DetectBiasService` (in `apps/api/src/ai/`) is pure data-in/data-out — takes plain text + custom terms, returns AI flags. (2) `BiasService` (new module) orchestrates — loads `scoring_config.custom_flagged_terms`, calls AI, persists flags as `bias_flags` rows, exposes override mutations. Two distinct endpoints: `POST /bias/check` is **stateless** (preview, used by the debounced editor — no DB writes); `POST /jobs/:id/bias-scan` is **stateful** (persists into `bias_flags` linked to the job). (3) `JobsService.publish()` calls `BiasService.scanJob()` _first_; if any persisted flag has `status='flagged'`, it throws `UnprocessableEntityException` with code `BIAS_CHECK_REQUIRED` + the flag list; otherwise it transitions to `published`. **Re-scan strategy:** each scan deletes existing `flagged` rows (clean slate) but preserves `overridden` and `resolved` rows (audit history). The recruiter must re-override any newly-flagged terms.

**Tech Stack:** NestJS module/service/repo pattern, Drizzle for `bias_flags` writes, OpenAI v6 SDK via `OpenAIService.generateStructured()`, shadcn Popover + Dialog for the override modal, sonner for toasts, debounced (1.5s) inline editor scans gated by `descriptionPlain.length >= 100`.

## Notes from prior slices' execution (read before starting)

- **Hook naming:** orval emits `useBiasControllerCheckV1` for `POST /bias/check`. The job-scoped endpoints (`POST /jobs/:id/bias-scan`, `GET /jobs/:id/bias-flags`, `POST /jobs/:id/bias-flags/:flagId/override`) live under the JobsController's path prefix and emit as `useJobsControllerBiasScanV1`, `useJobsControllerListBiasFlagsV1`, `useJobsControllerOverrideBiasFlagV1`. **Decision:** put job-scoped bias endpoints **on the BiasController** (not JobsController) so all bias logic stays in one module. Path is `POST /bias/jobs/:jobId/scan` etc. → emits `useBiasControllerScanJobV1` etc. This keeps `JobsController` focused. (See Task 5 below.)
- **OpenAI SDK v6.35:** all AI calls go through `OpenAIService.generateStructured()` which has the `as any` workaround for TS2589.
- **`.nullable()` over `.optional()`:** `biasFlagSchema.position_start` and `position_end` are already `.nullable()` (changed in 2.3). Persistence layer must store `null` not `undefined`.
- **`@nestjs/throttler` not registered:** the `/bias/check` endpoint can fire frequently from the debounced editor — protect with a manual rate-limit (per-user, ~10 req/min) using an in-memory `Map<userId, lastCallAt[]>`. For sprint this is acceptable; Slice 3.7 will move to Redis-backed Throttler.
- **AiModule is `@Global`:** `DetectBiasService` is auto-injectable everywhere — no need to import `AiModule` in `BiasModule`.
- **Mailpit running locally** — not used in this slice but stays running per env-setup.
- **TiptapEditor calls `onChange(html, plainText)` on every keystroke** — debounce in the parent form, not in the editor.
- **JobActions component pattern:** mutation calls go through orval hooks (e.g. `useJobsControllerPublishV1`). On 422 the orval-generated mutation throws — extract the response body via `error.response?.data` (the `aurahireFetcher` re-throws with the parsed body attached).

import { Injectable, Logger } from "@nestjs/common";
import { type BiasFlag, biasFlagListSchema } from "@aurahire/shared";

import { OpenAIService } from "./openai.service";
import {
  DETECT_BIAS_VERSION,
  DETECT_BIAS_SYSTEM_PROMPT,
  buildDetectBiasUserPrompt,
} from "./prompts/detect-bias";

export interface DetectBiasInput {
  /** Plain text to scan (typically descriptionPlain from a job). */
  text: string;
  /** Custom flagged terms from scoring_config.custom_flagged_terms. */
  customFlaggedTerms?: string[];
  requestId?: string;
}

export interface DetectBiasOutput {
  flags: BiasFlag[];
  latencyMs: number;
  model: string;
  promptVersion: string;
}

@Injectable()
export class DetectBiasService {
  private readonly logger = new Logger(DetectBiasService.name);

  constructor(private readonly openai: OpenAIService) {}

  async check(input: DetectBiasInput): Promise<DetectBiasOutput> {
    const reqId = input.requestId ?? "detect-bias";

    const userPrompt = buildDetectBiasUserPrompt({
      descriptionPlain: input.text,
      customFlaggedTerms: input.customFlaggedTerms ?? [],
    });

    const result = await this.openai.generateStructured({
      schema: biasFlagListSchema,
      schemaName: "BiasFlagList",
      systemPrompt: DETECT_BIAS_SYSTEM_PROMPT,
      userPrompt,
      requestId: `${reqId}:bias-v${DETECT_BIAS_VERSION}`,
    });

    this.logger.log(
      `[${reqId}] bias check completed: ${result.data.flags.length} flag(s) in ${result.latencyMs}ms`,
    );

    return {
      flags: result.data.flags,
      latencyMs: result.latencyMs,
      model: result.model,
      promptVersion: DETECT_BIAS_VERSION,
    };
  }
}
```

import { Inject, Injectable } from "@nestjs/common";
import { and, desc, eq } from "drizzle-orm";
import { biasFlagsTable, type BiasFlag, type NewBiasFlag } from "@aurahire/db";

import { DRIZZLE_CLIENT, type DrizzleClient } from "../../db/db.module";

@Injectable()
export class BiasRepository {
  constructor(@Inject(DRIZZLE_CLIENT) private readonly db: DrizzleClient) {}

  async insertMany(rows: NewBiasFlag[]): Promise<BiasFlag[]> {
    if (rows.length === 0) return [];
    return this.db.insert(biasFlagsTable).values(rows).returning();
  }

  async findByJobId(jobId: string): Promise<BiasFlag[]> {
    return this.db
      .select()
      .from(biasFlagsTable)
      .where(eq(biasFlagsTable.jobId, jobId))
      .orderBy(desc(biasFlagsTable.createdAt));
  }

  async findFlagged(jobId: string): Promise<BiasFlag[]> {
    return this.db
      .select()
      .from(biasFlagsTable)
      .where(
        and(
          eq(biasFlagsTable.jobId, jobId),
          eq(biasFlagsTable.status, "flagged"),
        ),
      )
      .orderBy(desc(biasFlagsTable.createdAt));
  }

  async findById(id: string): Promise<BiasFlag | null> {
    const [row] = await this.db
      .select()
      .from(biasFlagsTable)
      .where(eq(biasFlagsTable.id, id))
      .limit(1);
    return row ?? null;
  }

  async deleteFlaggedByJobId(jobId: string): Promise<number> {
    const rows = await this.db
      .delete(biasFlagsTable)
      .where(
        and(
          eq(biasFlagsTable.jobId, jobId),
          eq(biasFlagsTable.status, "flagged"),
        ),
      )
      .returning({ id: biasFlagsTable.id });
    return rows.length;
  }

  async markOverridden(
    id: string,
    overriddenBy: string,
    reason: string,
  ): Promise<BiasFlag> {
    const [row] = await this.db
      .update(biasFlagsTable)
      .set({
        status: "overridden",
        overrideReason: reason,
        overriddenBy,
        overriddenAt: new Date(),
      })
      .where(eq(biasFlagsTable.id, id))
      .returning();
    if (!row) throw new Error("Bias flag override failed");
    return row;
  }

  async markResolved(id: string): Promise<BiasFlag> {
    const [row] = await this.db
      .update(biasFlagsTable)
      .set({ status: "resolved" })
      .where(eq(biasFlagsTable.id, id))
      .returning();
    if (!row) throw new Error("Bias flag mark-resolved failed");
    return row;
  }
}
```

const RATE_LIMIT_WINDOW_MS = 60_000;
const RATE_LIMIT_MAX_CALLS = 10;

@Injectable()
export class BiasService {
  private readonly logger = new Logger(BiasService.name);
  private readonly rateLimitTracker = new Map<string, number[]>();

  constructor(
    private readonly detectBias: DetectBiasService,
    private readonly biasRepo: BiasRepository,
    private readonly jobsRepo: JobsRepository,
    private readonly scoringRepo: ScoringRepository,
    private readonly audit: AuditService,
  ) {}

  // -----------------------------------------------------------------
  // STATELESS PREVIEW (used by debounced editor)
  // -----------------------------------------------------------------

  async check(
    user: AuthUser,
    text: string,
    customTermsOverride: string[] | undefined,
  ): Promise<CheckBiasResponseDto["data"]> {
    if (user.role !== "recruiter" && user.role !== "admin") {
      throw new ForbiddenException({
        code: "FORBIDDEN",
        message: "Recruiter or admin role required",
      });
    }

    this.assertRateLimit(user.id);

    const customTerms =
      customTermsOverride ?? (await this.loadCustomFlaggedTerms());

    const result = await this.detectBias.check({
      text,
      customFlaggedTerms: customTerms,
      requestId: `bias-check:${user.id}`,
    });

    return {
      flags: result.flags.map((f) => ({
        term: f.term,
        category: f.category,
        severity: f.severity,
        explanation: f.explanation,
        suggestion: f.suggestion,
        positionStart: f.position_start,
        positionEnd: f.position_end,
      })),
      latencyMs: result.latencyMs,
      promptVersion: result.promptVersion,
      modelUsed: result.model,
    };
  }

  // -----------------------------------------------------------------
  // STATEFUL SCAN (persists into bias_flags)
  // -----------------------------------------------------------------

  async scanJob(
    user: AuthUser,
    jobId: string,
    requestMeta: { ipAddress?: string | null; userAgent?: string | null } = {},
  ): Promise<BiasFlagDto[]> {
    if (user.role !== "recruiter") {
      throw new ForbiddenException({
        code: "FORBIDDEN",
        message: "Recruiter role required",
      });
    }

    const job = await this.jobsRepo.findById(jobId);
    if (!job || job.recruiterId !== user.id) {
      throw new NotFoundException({
        code: "NOT_FOUND",
        message: "Job not found",
      });
    }

    const customTerms = await this.loadCustomFlaggedTerms();

    const aiResult = await this.detectBias.check({
      text: job.descriptionPlain,
      customFlaggedTerms: customTerms,
      requestId: `bias-scan:${jobId}`,
    });

    // Replace existing 'flagged' rows; preserve 'overridden' and 'resolved' history
    await this.biasRepo.deleteFlaggedByJobId(jobId);

    const newRows = aiResult.flags.map((f) => ({
      jobId,
      term: f.term,
      category: f.category,
      severity: f.severity,
      suggestion: f.suggestion,
      positionStart: f.position_start,
      positionEnd: f.position_end,
      status: "flagged" as const,
      promptVersion: aiResult.promptVersion,
      modelUsed: aiResult.model,
    }));

    const inserted = await this.biasRepo.insertMany(newRows);

    // Build map: term → explanation (in-memory only; not persisted)
    const explanationByTerm = new Map(
      aiResult.flags.map((f) => [f.term.toLowerCase(), f.explanation]),
    );

    await this.audit.log({
      actorId: user.id,
      actorType: "user",
      action: "job.bias_check_run",
      entityType: "job",
      entityId: jobId,
      details: {
        flagCount: inserted.length,
        categories: inserted.map((r) => r.category),
        promptVersion: aiResult.promptVersion,
        model: aiResult.model,
        latencyMs: aiResult.latencyMs,
      },
      ...requestMeta,
    });

    return inserted.map((row) =>
      this.toDto(row, explanationByTerm.get(row.term.toLowerCase()) ?? null),
    );
  }

  // -----------------------------------------------------------------
  // OVERRIDE
  // -----------------------------------------------------------------

  async override(
    user: AuthUser,
    jobId: string,
    flagId: string,
    reason: string,
    requestMeta: { ipAddress?: string | null; userAgent?: string | null } = {},
  ): Promise<BiasFlagDto> {
    if (user.role !== "recruiter") {
      throw new ForbiddenException({
        code: "FORBIDDEN",
        message: "Recruiter role required",
      });
    }

    const job = await this.jobsRepo.findById(jobId);
    if (!job || job.recruiterId !== user.id) {
      throw new NotFoundException({
        code: "NOT_FOUND",
        message: "Job not found",
      });
    }

    const flag = await this.biasRepo.findById(flagId);
    if (!flag || flag.jobId !== jobId) {
      throw new NotFoundException({
        code: "NOT_FOUND",
        message: "Flag not found",
      });
    }

    if (flag.status !== "flagged") {
      throw new BadRequestException({
        code: "FLAG_NOT_OVERRIDABLE",
        message: `Flag status is '${flag.status}', cannot override`,
      });
    }

    const updated = await this.biasRepo.markOverridden(flagId, user.id, reason);

    await this.audit.log({
      actorId: user.id,
      actorType: "user",
      action: "bias_flag.overridden",
      entityType: "bias_flag",
      entityId: flagId,
      details: {
        jobId,
        term: flag.term,
        category: flag.category,
        reasonSnippet: reason.slice(0, 200),
      },
      ...requestMeta,
    });

    return this.toDto(updated, null);
  }

  // -----------------------------------------------------------------
  // LIST
  // -----------------------------------------------------------------

  async listForJob(user: AuthUser, jobId: string): Promise<BiasFlagDto[]> {
    if (user.role !== "recruiter" && user.role !== "admin") {
      throw new ForbiddenException({
        code: "FORBIDDEN",
        message: "Recruiter or admin role required",
      });
    }

    const job = await this.jobsRepo.findById(jobId);
    if (!job) {
      throw new NotFoundException({
        code: "NOT_FOUND",
        message: "Job not found",
      });
    }
    if (user.role === "recruiter" && job.recruiterId !== user.id) {
      throw new NotFoundException({
        code: "NOT_FOUND",
        message: "Job not found",
      });
    }

    const rows = await this.biasRepo.findByJobId(jobId);
    return rows.map((row) => this.toDto(row, null));
  }

  // -----------------------------------------------------------------
  // INTERNAL: used by JobsService.publish() to gate
  // -----------------------------------------------------------------

  async findFlagged(jobId: string): Promise<BiasFlagDto[]> {
    const rows = await this.biasRepo.findFlagged(jobId);
    return rows.map((row) => this.toDto(row, null));
  }

  // -----------------------------------------------------------------
  // PRIVATE
  // -----------------------------------------------------------------

  private async loadCustomFlaggedTerms(): Promise<string[]> {
    const config = await this.scoringRepo.getActiveConfig();
    return config?.customFlaggedTerms ?? [];
  }

  private assertRateLimit(userId: string): void {
    const now = Date.now();
    const calls = this.rateLimitTracker.get(userId) ?? [];
    const recentCalls = calls.filter((t) => now - t < RATE_LIMIT_WINDOW_MS);
    if (recentCalls.length >= RATE_LIMIT_MAX_CALLS) {
      throw new TooManyRequestsException({
        code: "RATE_LIMITED",
        message: "Too many bias checks; slow down",
      });
    }
    recentCalls.push(now);
    this.rateLimitTracker.set(userId, recentCalls);
  }

  private toDto(
    row: {
      id: string;
      jobId: string;
      term: string;
      category: string;
      severity: string | null;
      suggestion: string | null;
      positionStart: number | null;
      positionEnd: number | null;
      status: string;
      overrideReason: string | null;
      overriddenBy: string | null;
      overriddenAt: Date | null;
      promptVersion: string;
      modelUsed: string;
      createdAt: Date;
    },
    explanation: string | null,
  ): BiasFlagDto {
    return {
      id: row.id,
      jobId: row.jobId,
      term: row.term,
      category: row.category,
      severity: row.severity,
      suggestion: row.suggestion,
      positionStart: row.positionStart,
      positionEnd: row.positionEnd,
      status: row.status,
      overrideReason: row.overrideReason,
      overriddenBy: row.overriddenBy,
      overriddenAt: row.overriddenAt ? row.overriddenAt.toISOString() : null,
      promptVersion: row.promptVersion,
      modelUsed: row.modelUsed,
      createdAt: row.createdAt.toISOString(),
      explanation,
    };
  }
}
```

      actorType: "user",
      action: "job.published",
      entityType: "job",
      entityId: id,

"use client";

import { useEffect, useRef, useState } from "react";
import { createSupabaseBrowserClient } from "@/lib/auth/client";

const MIN_LENGTH = 100;
const DEBOUNCE_MS = 1500;

export interface BiasFlagPreview {
  term: string;
  category: string;
  severity: "high" | "medium" | "low";
  explanation: string;
  suggestion: string;
  positionStart: number | null;
  positionEnd: number | null;
}

export function useDebouncedBiasCheck(descriptionPlain: string): {
  flags: BiasFlagPreview[];
  scanning: boolean;
} {
  const [flags, setFlags] = useState<BiasFlagPreview[]>([]);
  const [scanning, setScanning] = useState(false);
  const abortRef = useRef<AbortController | null>(null);

  useEffect(() => {
    if (!descriptionPlain || descriptionPlain.length < MIN_LENGTH) {
      setFlags([]);
      setScanning(false);
      return;
    }

    const handle = setTimeout(async () => {
      // cancel any in-flight call
      abortRef.current?.abort();
      const controller = new AbortController();
      abortRef.current = controller;

      setScanning(true);
      try {
        const supabase = createSupabaseBrowserClient();
        const {
          data: { session },
        } = await supabase.auth.getSession();
        if (!session) return;

        const apiUrl =
          process.env.NEXT_PUBLIC_API_URL ?? "http://localhost:3333";
        const res = await fetch(`${apiUrl}/api/v1/bias/check`, {
          method: "POST",
          headers: {
            Authorization: `Bearer ${session.access_token}`,
            "Content-Type": "application/json",
          },
          body: JSON.stringify({ text: descriptionPlain }),
          signal: controller.signal,
        });

        if (controller.signal.aborted) return;

        if (res.status === 429) {
          // silent; don't spam toasts
          return;
        }
        if (!res.ok) return;

        const body = (await res.json()) as {
          data: { flags: BiasFlagPreview[] };
        };
        setFlags(body.data.flags);
      } catch (err) {
        if ((err as Error).name === "AbortError") return;
        // silent
      } finally {
        if (!controller.signal.aborted) setScanning(false);
      }
    }, DEBOUNCE_MS);

    return () => {
      clearTimeout(handle);
      abortRef.current?.abort();
    };
  }, [descriptionPlain]);

  return { flags, scanning };
}
```

            id: string;
            term: string;
            category: string;

## Why This Slice Matters

This is **the upstream half of the thesis claim**. PII redaction + match scoring (2.6) demonstrate fairness _during_ evaluation. Bias detection on job descriptions demonstrates fairness _at the source_ — before a single application is ever submitted. It's the slice where AuraHire stops being "an AI recruiter that hides PII" and becomes "an AI recruiter that actively intervenes against biased hiring inputs."

Three thesis-defensible artifacts come out of this slice:

1. **The override audit trail** — every "rockstar" that survives publish has a written justification by a named user at a recorded timestamp. Examiners can query `bias_flags WHERE status='overridden'` and see exactly when and why a flag was bypassed.
2. **The 422 gate** — the system _prevents_ a non-overridden flag from publishing. Mitigation > monitoring.
3. **The transparent scan history** — the `bias_flags` table is a permanent record of what the AI flagged, what the recruiter accepted, and what they fixed. Slice 3.5 (Bias & Fairness Monitor) will visualize this for the admin.

If 2.6 was the integration test of the _evaluation_ pipeline, 2.7 is the integration test of the _intervention_ pipeline. Together, they ship the whole thesis.
