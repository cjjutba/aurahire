# Slice 3.1 — Admin Foundation: Stats + User Management + Job Moderation Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (in the executing session) to implement this plan task-by-task. Dispatch a fresh subagent per task; review between tasks; halt on failure. **This is the first slice of Day 3 — Admin Portal foundation.** It's three concerns in one slice (overview stats, user CRUD with state transitions, job moderation) but each is small. Pace per phase.

**Goal:** Land the **admin portal's working backbone** — Command Center, User Management, and Job Moderation — replacing the three "Coming in a future slice" stubs at `/admin`, `/admin/users`, `/admin/jobs`. Backend gets a new `AdminModule` with three sub-controllers (stats / users / jobs), each with corresponding service + repository + DTOs. All endpoints are `@Roles("admin")`-gated. By end of this slice: an admin can sign in, see live system KPIs (user counts, job counts, application volumes, score-band distribution), browse/filter all users in the system, suspend a user with a written reason, reactivate, change a user's role, force-delete a user (cascading from `auth.users` via SupabaseAdminService), force a password reset, browse/filter all jobs across the system, see bias-flag history per job, and archive a job from the admin view (bypassing recruiter ownership). Every consequential mutation writes to `audit_logs`.

**Architecture:** Three tightly-related concerns under one module — `AdminModule` — but split into per-resource sub-controllers so future slices (3.2 admin applications, 3.3 admin AI config) can mount alongside without ballooning a single file. Each sub-controller has its own service + repository. Stats are aggregation-only (no mutations); cached for 60s via the existing `@nestjs/cache-manager`. User mgmt mutations dual-write: the application-layer `profiles.status` field for visibility filtering, AND the auth-layer (`auth.users` via `SupabaseAdminService`) for hard delete + password operations. Hard self-protection: admin cannot suspend/delete/downgrade their own account (prevents lockout). Job moderation reuses `JobsRepository` for reads but exposes an admin-bypass archive that doesn't require ownership.

**Tech Stack:** NestJS module/sub-controller/service/repo pattern, Drizzle for application-layer queries, `SupabaseAdminService` (already exists from 1.4) for auth-layer ops, `@nestjs/cache-manager` for stats cache, audit via existing `AuditService`, frontend uses orval-generated TanStack Query hooks + shadcn `<Table>`/`<Sheet>`/`<Dialog>` primitives.

## Notes from prior slices' execution (read before starting)

- **Hook naming:** orval emits hooks as `use<Controller><Method>V1`. Sub-controllers will produce names like `useAdminStatsControllerOverviewV1`, `useAdminUsersControllerListV1`, `useAdminUsersControllerSuspendV1`, `useAdminUsersControllerReactivateV1`, `useAdminUsersControllerChangeRoleV1`, `useAdminUsersControllerDeleteV1`, `useAdminUsersControllerForcePasswordResetV1`, `useAdminJobsControllerListV1`, `useAdminJobsControllerGetByIdV1`, `useAdminJobsControllerArchiveV1`. **Verify exact names after codegen and update the frontend imports.**
- **OpenAI SDK v6.35:** no AI calls in this slice. Skip.
- **`HttpExceptionFilter` preserves extra fields** (Slice 2.7 fix). The 422 publish gate's pattern of `throw new HttpException({ code, message, ...extra })` works. We don't need it here, but it's available if you want to surface, e.g., `affectedJobsCount` on a delete-user warning.
- **`@nestjs/throttler` not registered:** no throttling on these endpoints. Admins are trusted; rate-limit if needed in 3.7.
- **`SupabaseAdminService.deleteUser()` exists** (1.4). Use it for the auth-layer side of user deletion.
- **`SupabaseAdminService.updatePassword()` exists** but for force-password-reset we want the *token-flow* (so the user lands on the reset page) — reuse the `auth_tokens` mechanism from 1.5. Don't update the password directly.
- **Profile cascade on delete:** `auth.users` deletion cascades to `profiles` only if the FK is wired with ON DELETE CASCADE. Check with Supabase MCP if unclear; the schema comment at `profiles.id` says "mirrors auth.users.id; FK enforced via Supabase trigger" — so on `auth.users` delete, the `profiles` row may be auto-deleted too. **In that case** the `status='deleted'` set is redundant — but doing both is defensive and fine for sprint.
- **`PortalShell` already accepts role="admin"** (per `apps/web/app/(admin)/layout.tsx`) so the sidebar nav links for admin already exist.
- **Three "Coming in a future slice" pages exist** at `/admin`, `/admin/users`, `/admin/jobs` and need to be replaced (not added).
- **Day 2 polish (2.8) added `loading.tsx` for some routes** — this slice adds three more for the admin pages it ships.

```ts
import { Inject, Injectable } from "@nestjs/common";
import { and, asc, desc, eq, gte, ilike, lte, or, sql } from "drizzle-orm";
import {
  auditLogsTable,
  profilesTable,
  type Profile,
} from "@aurahire/db";

import { DRIZZLE_CLIENT, type DrizzleClient } from "../../../db/db.module";

export interface ListAdminUsersFilters {
  role?: "candidate" | "recruiter" | "admin";
  status?: "active" | "suspended" | "deleted";
  q?: string;
  createdFrom?: Date;
  createdTo?: Date;
  page: number;
  limit: number;
}

@Injectable()
export class AdminUsersRepository {
  constructor(@Inject(DRIZZLE_CLIENT) private readonly db: DrizzleClient) {}

  async list(filters: ListAdminUsersFilters): Promise<{ rows: Profile[]; total: number }> {
    const offset = (filters.page - 1) * filters.limit;
    const conditions = [];
    if (filters.role) conditions.push(eq(profilesTable.role, filters.role));
    if (filters.status) conditions.push(eq(profilesTable.status, filters.status));
    if (filters.q) {
      const pattern = `%${filters.q}%`;
      conditions.push(
        or(
          ilike(profilesTable.fullName, pattern),
          ilike(profilesTable.email, pattern),
        )!,
      );
    }
    if (filters.createdFrom) conditions.push(gte(profilesTable.createdAt, filters.createdFrom));
    if (filters.createdTo) conditions.push(lte(profilesTable.createdAt, filters.createdTo));

    const where = conditions.length > 0 ? and(...conditions) : undefined;

    const rows = await this.db
      .select()
      .from(profilesTable)
      .where(where)
      .orderBy(desc(profilesTable.createdAt))
      .limit(filters.limit)
      .offset(offset);

    const totalRows = await this.db
      .select({ c: sql<number>`count(*)::int` })
      .from(profilesTable)
      .where(where);

    return { rows, total: totalRows[0]?.c ?? 0 };
  }

  async findById(id: string): Promise<Profile | null> {
    const [row] = await this.db
      .select()
      .from(profilesTable)
      .where(eq(profilesTable.id, id))
      .limit(1);
    return row ?? null;
  }

  async update(id: string, patch: Partial<Profile>): Promise<Profile> {
    const [row] = await this.db
      .update(profilesTable)
      .set({ ...patch, updatedAt: new Date() })
      .where(eq(profilesTable.id, id))
      .returning();
    if (!row) throw new Error("Profile update failed");
    return row;
  }

  async countAuditEntriesForUser(userId: string): Promise<number> {
    const rows = await this.db
      .select({ c: sql<number>`count(*)::int` })
      .from(auditLogsTable)
      .where(eq(auditLogsTable.actorId, userId));
    return rows[0]?.c ?? 0;
  }
}
```

```ts
  async archive(
    actor: AuthUser,
    id: string,
    requestMeta: { ipAddress?: string | null; userAgent?: string | null } = {},
  ): Promise<AdminJobDetailDto> {
    const row = await this.jobsRepo.findById(id);
    if (!row) throw new NotFoundException({ code: "NOT_FOUND", message: "Job not found" });

    if (row.status === "archived") {
      // Idempotent: return current state
      return this.getById(id);

      entityType: "job",
      entityId: id,
      details: {
        previousStatus: row.status,
        recruiterId: row.recruiterId,
      },
      ...requestMeta,
    });

    // Invalidate public job cache (sprint = rely on TTL; 3.7 will add granular keyset)
    // No explicit invalidation needed; the 60s TTL on JobsService cache will refresh

    return this.getById(id);
  }
```

```ts
import { ilike, or } from "drizzle-orm";

interface ListForAdminFilters {
  status?: "draft" | "published" | "archived";
  recruiterId?: string;
  hasBiasFlags?: boolean;
  q?: string;
  page: number;
  limit: number;
}

async listForAdmin(filters: ListForAdminFilters): Promise<{
  rows: Array<JobWithCompany & { recruiter: { id: string; fullName: string; email: string } }>;
  total: number;
}> {
  const offset = (filters.page - 1) * filters.limit;
  const conditions = [];
  if (filters.status) conditions.push(eq(jobsTable.status, filters.status));
  if (filters.recruiterId) conditions.push(eq(jobsTable.recruiterId, filters.recruiterId));
  if (filters.q) {
    const pattern = `%${filters.q}%`;
    conditions.push(or(ilike(jobsTable.title, pattern), ilike(jobsTable.descriptionPlain, pattern))!);
  }
  if (filters.hasBiasFlags) {
    conditions.push(
      sql`EXISTS (SELECT 1 FROM ${biasFlagsTable} WHERE ${biasFlagsTable.jobId} = ${jobsTable.id})`,
    );
  }
  const where = conditions.length > 0 ? and(...conditions) : undefined;

  const rows = await this.db
    .select({
      job: jobsTable,
      company: companiesTable,
      recruiter: profilesTable,
    })
    .from(jobsTable)
    .innerJoin(companiesTable, eq(companiesTable.id, jobsTable.companyId))
    .innerJoin(profilesTable, eq(profilesTable.id, jobsTable.recruiterId))
    .where(where)
    .orderBy(desc(jobsTable.createdAt))
    .limit(filters.limit)
    .offset(offset);

  const totalRows = await this.db
    .select({ c: sql<number>`count(*)::int` })
    .from(jobsTable)
    .where(where);

  return {
    rows: rows.map((r) => ({
      ...r.job,
      company: r.company,
      recruiter: { id: r.recruiter.id, fullName: r.recruiter.fullName, email: r.recruiter.email },
    })),
    total: totalRows[0]?.c ?? 0,
  };
}

async findByIdWithCompanyAndRecruiter(id: string): Promise<
  | (JobWithCompany & { recruiter: { id: string; fullName: string; email: string } })
  | null
> {
  const [row] = await this.db
    .select({
      job: jobsTable,
      company: companiesTable,
      recruiter: profilesTable,
    })
    .from(jobsTable)
    .innerJoin(companiesTable, eq(companiesTable.id, jobsTable.companyId))
    .innerJoin(profilesTable, eq(profilesTable.id, jobsTable.recruiterId))
    .where(eq(jobsTable.id, id))
    .limit(1);
  return row
    ? {
        ...row.job,
        company: row.company,
        recruiter: {
          id: row.recruiter.id,
          fullName: row.recruiter.fullName,
          email: row.recruiter.email,
        },
      }
    : null;
}
```

```tsx
import { useState, useTransition } from "react";
import { Input } from "@/components/ui/input";
import { Select, SelectContent, SelectItem, SelectTrigger, SelectValue } from "@/components/ui/select";
import { Button } from "@/components/ui/button";

interface Props {
  initialFilters: { role?: string; status?: string; q?: string };
}

export function FiltersClient({ initialFilters }: Props) {
  const router = useRouter();
  const sp = useSearchParams();
  const [isPending, startTransition] = useTransition();
  const [role, setRole] = useState(initialFilters.role ?? "all");
  const [status, setStatus] = useState(initialFilters.status ?? "all");
  const [q, setQ] = useState(initialFilters.q ?? "");

  function apply() {
    const next = new URLSearchParams(sp.toString());
    if (role && role !== "all") next.set("role", role);
    else next.delete("role");
    if (status && status !== "all") next.set("status", status);
    else next.delete("status");
    if (q) next.set("q", q);
    else next.delete("q");
    next.delete("page");
    startTransition(() => router.push(`?${next.toString()}`));
  }

  function reset() {
    setRole("all");
    setStatus("all");
    setQ("");
    startTransition(() => router.push("?"));
  }

  return (
    <div className="flex flex-wrap items-end gap-3 rounded-[var(--radius-lg)] border border-[var(--color-hairline)] bg-[var(--color-canvas)] p-4">
      <div className="min-w-[120px]">
        <label className="mb-1 block text-xs font-semibold uppercase tracking-wider text-[var(--color-muted)]">
          Role
        </label>

          <SelectTrigger><SelectValue /></SelectTrigger>
```

**Step 4:** `_action-modals-client.tsx` — Suspend / Reactivate / ChangeRole / Delete / ForcePasswordReset modals:

```tsx
"use client";

import { useState, useEffect } from "react";
import { useRouter } from "next/navigation";
import { toast } from "sonner";
import {
  Dialog,
  DialogContent,
  DialogDescription,
  DialogFooter,
  DialogHeader,
  DialogTitle,
} from "@/components/ui/dialog";
import { Button } from "@/components/ui/button";
import { Textarea } from "@/components/ui/textarea";
import { Input } from "@/components/ui/input";
import { Select, SelectContent, SelectItem, SelectTrigger, SelectValue } from "@/components/ui/select";
import { createSupabaseBrowserClient } from "@/lib/auth/client";

interface UserRef {
  id: string;
  fullName: string;
  email: string;
  role: string;
  status: string;
}

export type PendingAction =
  | { kind: "suspend"; user: UserRef }
  | { kind: "reactivate"; user: UserRef }
  | { kind: "changeRole"; user: UserRef }
  | { kind: "delete"; user: UserRef }
  | { kind: "forcePasswordReset"; user: UserRef };

interface Props {
  action: PendingAction | null;
  onClose: () => void;
}

async function authedFetch(path: string, init?: RequestInit) {
  const supabase = createSupabaseBrowserClient();
  const { data: { session } } = await supabase.auth.getSession();
  if (!session) throw new Error("Not signed in");
  const apiUrl = process.env.NEXT_PUBLIC_API_URL ?? "http://localhost:3333";
  return fetch(`${apiUrl}${path}`, {
    ...init,
    headers: {
      ...(init?.headers ?? {}),
      Authorization: `Bearer ${session.access_token}`,
    },
  });
}

export function ActionModalsClient({ action, onClose }: Props) {
  const router = useRouter();
  const [working, setWorking] = useState(false);
  const [reason, setReason] = useState("");
  const [emailConfirm, setEmailConfirm] = useState("");
  const [newRole, setNewRole] = useState<"candidate" | "recruiter" | "admin">("candidate");
  const [resetUrl, setResetUrl] = useState<string | null>(null);

  useEffect(() => {
    setReason("");
    setEmailConfirm("");
    setResetUrl(null);
    if (action?.kind === "changeRole") setNewRole(action.user.role as "candidate" | "recruiter" | "admin");
  }, [action]);

  if (!action) return null;
  const { user } = action;

  async function suspend() {
    if (reason.trim().length < 10) {
      toast.error("Reason must be at least 10 characters");
      return;
    }
    setWorking(true);
    try {
      const res = await authedFetch(`/api/v1/admin/users/${user.id}/suspend`, {
        method: "POST",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify({ reason: reason.trim() }),
      });
      if (!res.ok) {
        const body = await res.json().catch(() => ({}));
        toast.error("Suspend failed", { description: (body as { message?: string }).message });
        return;
      }
      toast.success("User suspended");
      router.refresh();
      onClose();
    } finally {
      setWorking(false);
    }
  }

  async function reactivate() {
    setWorking(true);
    try {
      const res = await authedFetch(`/api/v1/admin/users/${user.id}/reactivate`, { method: "POST" });
      if (!res.ok) { toast.error("Reactivate failed"); return; }
      toast.success("User reactivated");
      router.refresh();
      onClose();
    } finally { setWorking(false); }
  }

  async function changeRole() {
    if (newRole === user.role) { toast.error("Pick a different role"); return; }
    setWorking(true);
    try {
      const res = await authedFetch(`/api/v1/admin/users/${user.id}/role`, {
        method: "PATCH",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify({ newRole }),
      });
      if (!res.ok) {
        const body = await res.json().catch(() => ({}));
        toast.error("Role change failed", { description: (body as { message?: string }).message });
        return;
      }
      toast.success(`Role changed to ${newRole}`);
      router.refresh();
      onClose();
    } finally { setWorking(false); }
  }

  async function deleteUser() {
    if (emailConfirm !== user.email) {
      toast.error("Email confirmation does not match");
      return;
    }
    setWorking(true);
    try {
      const res = await authedFetch(`/api/v1/admin/users/${user.id}`, { method: "DELETE" });
      if (!res.ok) {
        const body = await res.json().catch(() => ({}));
        toast.error("Delete failed", { description: (body as { message?: string }).message });
        return;
      }
      toast.success("User deleted");
      router.refresh();
      onClose();
    } finally { setWorking(false); }
  }

  async function forcePasswordReset() {
    setWorking(true);
    try {
      const res = await authedFetch(`/api/v1/admin/users/${user.id}/force-password-reset`, { method: "POST" });
      if (!res.ok) { toast.error("Reset failed"); return; }
      const body = (await res.json()) as { data: { resetUrl: string; emailSent: boolean } };
      setResetUrl(body.data.resetUrl);
      toast.success(body.data.emailSent ? "Reset email sent + URL ready" : "Reset URL ready (email failed)");
    } finally { setWorking(false); }
  }

  // ---------------- RENDER ----------------

  return (
    <Dialog open={!!action} onOpenChange={(o) => { if (!o) onClose(); }}>
      <DialogContent className="max-w-lg">
        {action.kind === "suspend" && (
          <>
            <DialogHeader>
              <DialogTitle>Suspend {user.fullName}</DialogTitle>
              <DialogDescription>
                The user will lose access immediately. Reason is captured in the audit log.
              </DialogDescription>
            </DialogHeader>
            <Textarea
              value={reason}
              onChange={(e) => setReason(e.target.value)}
              placeholder="Reason (≥10 characters)"
              rows={3}
            />
            <DialogFooter>
              <Button variant="outline" onClick={onClose} className="rounded-[var(--radius-pill)]">Cancel</Button>
              <Button
                onClick={suspend}
                disabled={working || reason.trim().length < 10}
                className="rounded-[var(--radius-pill)] bg-[var(--color-status-danger)] hover:bg-[var(--color-status-danger)]"
              >
                {working ? "Suspending..." : "Confirm suspend"}
              </Button>
            </DialogFooter>
          </>
        )}

        {action.kind === "reactivate" && (
          <>
            <DialogHeader>
              <DialogTitle>Reactivate {user.fullName}?</DialogTitle>
              <DialogDescription>The user will regain access.</DialogDescription>
            </DialogHeader>
            <DialogFooter>
              <Button variant="outline" onClick={onClose} className="rounded-[var(--radius-pill)]">Cancel</Button>
              <Button onClick={reactivate} disabled={working} className="rounded-[var(--radius-pill)] bg-[var(--color-primary)]">
                {working ? "..." : "Reactivate"}
              </Button>
            </DialogFooter>
          </>
        )}

        {action.kind === "changeRole" && (
          <>
            <DialogHeader>
              <DialogTitle>Change role for {user.fullName}</DialogTitle>
              <DialogDescription>Currently: <strong>{user.role}</strong></DialogDescription>
            </DialogHeader>
            <Select value={newRole} onValueChange={(v) => setNewRole(v as "candidate" | "recruiter" | "admin")}>
              <SelectTrigger><SelectValue /></SelectTrigger>
              <SelectContent>
                <SelectItem value="candidate">Candidate</SelectItem>
                <SelectItem value="recruiter">Recruiter</SelectItem>
                <SelectItem value="admin">Admin</SelectItem>
              </SelectContent>
            </Select>
            <DialogFooter>
              <Button variant="outline" onClick={onClose} className="rounded-[var(--radius-pill)]">Cancel</Button>
              <Button onClick={changeRole} disabled={working || newRole === user.role} className="rounded-[var(--radius-pill)] bg-[var(--color-primary)]">
                {working ? "..." : `Change to ${newRole}`}
              </Button>
            </DialogFooter>
          </>
        )}

        {action.kind === "delete" && (
          <>
            <DialogHeader>
              <DialogTitle>Delete {user.fullName}?</DialogTitle>
              <DialogDescription>
                This soft-deletes the profile (status='deleted') and removes the auth.users row. Their data persists for audit. Type <strong>{user.email}</strong> to confirm.
              </DialogDescription>
            </DialogHeader>
            <Input
              value={emailConfirm}
              onChange={(e) => setEmailConfirm(e.target.value)}
              placeholder={user.email}
            />
            <DialogFooter>
              <Button variant="outline" onClick={onClose} className="rounded-[var(--radius-pill)]">Cancel</Button>
              <Button
                onClick={deleteUser}
                disabled={working || emailConfirm !== user.email}
                className="rounded-[var(--radius-pill)] bg-[var(--color-status-danger)] hover:bg-[var(--color-status-danger)]"
              >
                {working ? "Deleting..." : "Confirm delete"}
              </Button>
            </DialogFooter>
          </>
        )}

        {action.kind === "forcePasswordReset" && (
          <>
            <DialogHeader>
              <DialogTitle>Force password reset for {user.fullName}?</DialogTitle>
              <DialogDescription>
                Generates a 24h reset token and emails the user. The reset URL will also be displayed here so you can deliver it manually if email fails.
              </DialogDescription>
            </DialogHeader>
            {!resetUrl ? (
              <DialogFooter>
                <Button variant="outline" onClick={onClose} className="rounded-[var(--radius-pill)]">Cancel</Button>
                <Button onClick={forcePasswordReset} disabled={working} className="rounded-[var(--radius-pill)] bg-[var(--color-primary)]">
                  {working ? "..." : "Generate + email"}
                </Button>
              </DialogFooter>
```

```tsx
    q?: string;

  title: string;
  status: string;
  publishedAt: string | null;

  applicationsCount: number;

    return <div className="text-[var(--color-status-danger)]">Failed to load jobs.</div>;
  }
  const body = (await res.json()) as {
    data: JobRow[];
    meta: { page: number; limit: number; total: number; totalPages: number };

}
```

```tsx
"use client";

import { useEffect, useState } from "react";
import { useRouter } from "next/navigation";
import { toast } from "sonner";
import { Sheet, SheetContent, SheetHeader, SheetTitle } from "@/components/ui/sheet";
import { Button } from "@/components/ui/button";
import { BiasFlagsList } from "@/components/bias/bias-flags-list";
import { createSupabaseBrowserClient } from "@/lib/auth/client";

interface Detail {
  id: string;
  title: string;
  status: string;
  description: string;
  descriptionPlain: string;
  requiredSkills: string[];
  recruiter: { id: string; fullName: string; email: string };
  company: { id: string; name: string };
  biasFlags: Array<{
    id: string;
    term: string;
    category: string;
    severity: string | null;
    status: "flagged" | "overridden" | "resolved";
    overrideReason: string | null;
  }>;
}

interface Props { jobId: string; open: boolean; onClose: () => void; }

export function JobDetailSheetClient({ jobId, open, onClose }: Props) {
  const router = useRouter();
  const [detail, setDetail] = useState<Detail | null>(null);
  const [working, setWorking] = useState(false);

  useEffect(() => {
    void load();
    async function load() {
      const supabase = createSupabaseBrowserClient();
      const { data: { session } } = await supabase.auth.getSession();
      if (!session) return;
      const apiUrl = process.env.NEXT_PUBLIC_API_URL ?? "http://localhost:3333";
      const res = await fetch(`${apiUrl}/api/v1/admin/jobs/${jobId}`, {
        headers: { Authorization: `Bearer ${session.access_token}` },
        cache: "no-store",
      });
      if (!res.ok) return;
      const body = (await res.json()) as { data: Detail };
      setDetail(body.data);
    }
  }, [jobId]);

  async function archive() {
    if (!detail) return;
    if (!window.confirm("Archive this job?")) return;
    setWorking(true);
    try {
      const supabase = createSupabaseBrowserClient();
      const { data: { session } } = await supabase.auth.getSession();
      if (!session) return;
      const apiUrl = process.env.NEXT_PUBLIC_API_URL ?? "http://localhost:3333";
      const res = await fetch(`${apiUrl}/api/v1/admin/jobs/${jobId}/archive`, {
        method: "POST",
        headers: { Authorization: `Bearer ${session.access_token}` },
      });
      if (!res.ok) { toast.error("Archive failed"); return; }
      toast.success("Job archived");
      router.refresh();
      onClose();
    } finally { setWorking(false); }
  }

  return (
    <Sheet open={open} onOpenChange={(o) => { if (!o) onClose(); }}>
      <SheetContent side="right" className="w-full sm:max-w-2xl overflow-y-auto bg-[var(--color-canvas)]">
        <SheetHeader>
          <SheetTitle>{detail?.title ?? "Loading…"}</SheetTitle>
        </SheetHeader>
        {detail && (
          <div className="mt-6 space-y-6">
            <div>
              <p className="text-xs font-semibold uppercase tracking-wider text-[var(--color-muted)]">Recruiter</p>
              <p className="mt-1 text-sm text-[var(--color-ink)]">{detail.recruiter.fullName} · {detail.recruiter.email}</p>
            </div>
            <div>
              <p className="text-xs font-semibold uppercase tracking-wider text-[var(--color-muted)]">Company</p>
              <p className="mt-1 text-sm text-[var(--color-ink)]">{detail.company.name}</p>
            </div>
            <div>
              <p className="text-xs font-semibold uppercase tracking-wider text-[var(--color-muted)]">Description</p>
              <p className="mt-1 max-h-48 overflow-y-auto whitespace-pre-wrap text-sm text-[var(--color-body)]">
                {detail.descriptionPlain}
              </p>
            </div>
            {detail.biasFlags.length > 0 && (
              <div>
                <p className="text-xs font-semibold uppercase tracking-wider text-[var(--color-muted)]">Bias Flag History</p>
                <div className="mt-2">
                  <BiasFlagsList
                    flags={detail.biasFlags.map((f) => ({
                      id: f.id,
                      term: f.term,
                      category: f.category,
                      severity: f.severity as "high" | "medium" | "low" | null,
                      status: f.status,
                      explanation: null,
                      suggestion: null,
                    }))}
                    title={`${detail.biasFlags.length} flag${detail.biasFlags.length === 1 ? "" : "s"} on record`}
                  />
                </div>
                {detail.biasFlags.filter((f) => f.status === "overridden").map((f) => (
                  <div key={f.id} className="mt-2 rounded-[var(--radius-md)] bg-[var(--color-surface-soft)] p-3 text-xs">
                    <strong>"{f.term}"</strong> overridden — {f.overrideReason}
                  </div>
                ))}
              </div>
            )}
            <div className="border-t border-[var(--color-hairline)] pt-4">
              {detail.status !== "archived" && (
                <Button onClick={archive} disabled={working} className="rounded-[var(--radius-pill)] bg-[var(--color-status-danger)]">
                  {working ? "Archiving…" : "Archive job"}
                </Button>
              )}
            </div>
          </div>
        )}
      </SheetContent>
    </Sheet>
  );
}
```

## Why This Slice Matters

The admin portal is the **operational control surface** that makes the rest of the system trustworthy. Everything Day 1 + Day 2 built — applications, scores, bias flags, audit logs — accumulates state, and if a recruiter posts a problematic job or a candidate's account needs intervention, there has to be a person who can act. 3.1 ships that person's tools.

Three thesis-relevant moments come out of this slice:
1. **The Command Center** is the first surface where a thesis examiner can see the system's volume and health at a glance. The numbers are real (not stubbed) — that demonstrates working pipelines.
2. **The audit-on-everything pattern** continues. Every suspend/delete/role-change writes a row that 3.4's audit log surface will display. Examiners can trace any administrative decision to a user, a timestamp, and a reason.
3. **Self-lockout protection** is a tiny detail that signals careful design. The system refuses to let an admin lock themselves out — a small thing that catches a real-world failure mode.

This slice is not glamorous, but the rest of Day 3 (admin oversight, AI config, audit, bias monitor) all build on this foundation. Get it right and the next 5 admin slices each take 60-90 minutes instead of fighting the foundation.
